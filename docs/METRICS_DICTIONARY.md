# Словарь метрик

Все определения одинаково используются в ноутбуке Pandas и SQL-запросах BigQuery.

| Метрика | Определение | Фильтр / знаменатель | Зачем нужна |
|---|---|---|---|
| GMV | Сумма `order_value` | `status != 'Cancelled'` | Оценка оборота после исключения отмен |
| Чистая выручка, прокси | Сумма `order_value` | `status NOT IN ('Cancelled', 'Returned')` | Выручка, сохранившаяся после возвратов и отмен |
| Валовая прибыль, прокси | Чистая выручка минус `product_cost` | Только успешные заказы | Прибыль до логистики, маркетинга и налогов |
| Валовая маржа | Валовая прибыль / чистая выручка | Чистая выручка > 0 | Сравнение эффективности выручки |
| Доля отмен | Отменённые заказы / все заказы | Все заказы | Контроль проблем до выполнения заказа |
| Доля возвратов | Возвращённые заказы / заказы без отмен | Заказы без `Cancelled` | Контроль потерь после покупки |
| AOV | Чистая выручка / успешные заказы | Успешные заказы с положительной выручкой | Средний успешный чек |
| Доля повторных покупателей | Клиенты с 2+ успешными заказами / все покупатели | Заказы без отмен и возвратов | Оценка способности продукта возвращать покупателей |
| Конверсия сессии в покупку | Сессии с `purchase` / все сессии | Уникальный `session_id` | Эффективность продуктовой воронки |
| Удержание M1 | Покупатели, повторившие покупку через месяц / размер созревшей когорты | Когорта первой успешной покупки | Раннее удержание покупателей |
| RFM Recency | Дни после последнего net-заказа | На дату snapshot | Давность последней покупки |
| RFM Frequency | Количество уникальных net-заказов | На клиента | Частота покупок |
| RFM Monetary | Сумма Net Revenue | На клиента | Денежная ценность клиента |
| Доля возвратов товаров | Возвращённые товары / товары без отмен | На категорию | Поиск товарных проблем |
| Стоимость залежавшихся запасов | Себестоимость непроданного товара старше 180 дней | `sold_at IS NULL` | Оценка замороженного капитала |
| Вклад на пользователя | Средняя валовая прибыль после субсидии | Все участники эксперимента | Экономическая защитная метрика A/B-теста |

## Гранулярность

Главная аналитическая витрина `order_mart` имеет гранулярность:

> одна строка = один уникальный `order_id`

Перед объединением с заказами `order_items` агрегируются до `order_id`. После создания витрины выполняется проверка:

```text
COUNT(rows) = COUNT(DISTINCT order_id)
```

## Важные оговорки

- Чистая выручка и валовая прибыль являются прокси-метриками.
- В источнике нет налогов, маркетинговых затрат, стоимости поддержки и полной стоимости доставки.
- Удержание отражает повторную покупку по календарным месяцам, а не активность в приложении.
- A/B-данные симулируются и не доказывают эффект в реальном бизнесе.
